# Evo Parking Navigation

Evo Parking Navigation is a prototype of a contextual parking layer for the Evo car-share app. Evo vehicles are sometimes parked inside multi-level parking structures rather than on the street, and the app only drops a pin at the street address — so a driver can reserve a car, walk to the address, and have no idea which floor it's on, how to get into the lot, or whether the lot is about to close. This layer surfaces lot status, floor level, access instructions, and a closing-time warning directly inside the existing tap-car → reserve → navigate → end-trip flow, adding no new screens and staying invisible for street-parked cars.
